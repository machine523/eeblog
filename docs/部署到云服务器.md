# 🌐 把博客部署到云服务器（小白完整版）

> 目标：让全世界都能通过 `http://你的域名` 或 `http://服务器IP` 访问你的博客。
> 原理一句话：这个博客是**纯静态网站**——构建出来一堆 html/css/js 文件，用 Nginx 这样的 Web 服务器把它们"端"出去就行，不需要数据库、不需要后端。

---

## 第 0 步：购买服务器时的选择

- **配置**：1 核 1G 或 1 核 2G 完全够（静态网站几乎不耗资源）
- **系统**：选 **Ubuntu 22.04**（本文命令都以它为准）
- **安全组 / 防火墙**：放行 **22**（SSH 登录）、**80**（HTTP）、**443**（HTTPS，后面配域名证书用）
- 记下：**服务器公网 IP**、**登录用户名**（一般是 `root` 或 `ubuntu`）、**密码或密钥**

---

## 第 1 步：在服务器上安装 Nginx

用 SSH 登录服务器（Windows 可用 PowerShell 直接 `ssh root@你的IP`），然后：

```bash
apt update
apt install -y nginx
mkdir -p /var/www/blog
```

装完后，浏览器访问 `http://你的IP` 能看到 "Welcome to nginx" 就说明 Nginx 正常了。

---

## 第 2 步：本机构建 + 上传网站文件

在你**自己电脑**的博客目录里：

```bash
npm run build
```

会生成 `dist/` 文件夹——这就是网站的全部。把它上传到服务器（三选一）：

**方式 A：命令行 scp（Windows PowerShell / Mac 终端通用）**

```bash
scp -r dist/* root@你的IP:/var/www/blog/
```

**方式 B：图形工具 WinSCP**（适合不喜欢命令行的）
左边打开本地 `dist` 文件夹，右边打开服务器 `/var/www/blog`，全选拖过去。

**方式 C：什么都不用传** —— 直接跳到「第 4 步：自动部署」，以后连构建带上传全自动。

---

## 第 3 步：配置 Nginx

把本项目里的 `deploy/nginx.conf` 上传到服务器：

```bash
scp deploy/nginx.conf root@你的IP:/etc/nginx/sites-available/blog
```

然后在服务器上启用它：

```bash
ln -s /etc/nginx/sites-available/blog /etc/nginx/sites-enabled/blog
rm -f /etc/nginx/sites-enabled/default
nginx -t          # 检查配置有没有写错
systemctl reload nginx
```

浏览器再访问 `http://你的IP`，就是你的博客了 🎉

> ⚠️ `nginx.conf` 里那行 `try_files $uri $uri/ /index.html;` **必须保留**——
> 没有它，直接访问 `/posts/某篇文章` 这样的网址会 404（这是单页应用的标准配置）。

---

## 第 4 步（推荐）：配置自动部署，以后发文章全自动

手动上传每次都要重复第 2、3 步，很烦。配好自动部署后流程变成：

**你在任何电脑（甚至 GitHub 网页）上改文章 → push → 几分钟后网站自动更新。**

### 4.1 原理

项目里已经放好了 `.github/workflows/deploy.yml`：每次 push 到 main 分支，GitHub 会自动构建并把 `dist/` 传到你的服务器。

### 4.2 准备工作：生成一对 SSH 密钥（给 GitHub 用的专用钥匙）

在自己电脑的 PowerShell 里：

```powershell
ssh-keygen -t ed25519 -f "$env:USERPROFILE\.ssh\blog-deploy" -N '""'
```

会生成两个文件：`blog-deploy`（私钥，保密！）和 `blog-deploy.pub`（公钥，可以公开）。

### 4.3 把公钥装到服务器上

```bash
ssh root@你的IP "mkdir -p ~/.ssh && echo '这里粘贴 blog-deploy.pub 的整行内容' >> ~/.ssh/authorized_keys"
```

### 4.4 在 GitHub 仓库里填 4 个 Secrets

打开你的 GitHub 仓库 → **Settings → Secrets and variables → Actions → New repository secret**，逐个添加：

| 名称 | 内容 | 示例 |
| --- | --- | --- |
| `SERVER_HOST` | 服务器公网 IP | `123.45.67.89` |
| `SERVER_USER` | SSH 登录用户名 | `root` |
| `SERVER_SSH_KEY` | 私钥 `blog-deploy` 文件的**全部内容**（包括 BEGIN/END 两行） | — |
| `SERVER_PORT` | SSH 端口 | `22` |

### 4.5 完成 ✅

以后每次 `git push`，去仓库的 **Actions** 标签页能看到部署进度，绿色勾 = 已上线。

---

## 第 5 步（可选）：绑定域名 + HTTPS

1. 在域名服务商那里加一条 **A 记录**：`@` 或 `blog` → 你的服务器 IP
2. 把 `deploy/nginx.conf` 里的 `server_name _;` 改成 `server_name 你的域名;` 并重新加载 Nginx
3. 服务器上运行一条命令搞定免费 HTTPS 证书：

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d 你的域名
```

之后就能用 `https://你的域名` 访问，证书会自动续期。
