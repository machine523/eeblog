# 🎨 博客样式 / 风格修改指南

> 想换字体、调字号、改颜色、动首页排版？都在这一篇里。
> 所有修改都在本地 VSCode 里进行，改完保存 → `npm run dev` 本地预览 →
> 满意后 提交+推送，几分钟后线上生效。
>
> **改坏了怎么办**：终端执行 `git checkout -- 文件名` 即可还原成改动前的样子，
> 所以大胆试，随时可以一键后悔。

---

## 2. 换字体

打开 `tailwind.config.js`，找到 `fontFamily`（约第 24 行）：

```js
fontFamily: {
  sans:  ['"Microsoft YaHei"', '"Noto Sans SC"', 'ui-sans-serif', ...],  // 正文
  serif: ['"Microsoft YaHei"', '"Noto Serif SC"', 'Georgia', ...],       // 大标题
  mono:  ['"JetBrains Mono"', 'ui-monospace', ...],                      // 代码块
},
```

**规则**：浏览器从左到右找字体，找到第一个"访问者电脑里装了的"就用它。
所以想换字体，**把你想要的字体名放到数组最前面**即可，后面的留着当备胎。

常用中文字体名（直接复制）：

| 字体 | 写法 |
| --- | --- |
| 微软雅黑 | `'"Microsoft YaHei"'` |
| 苹方（苹果） | `'"PingFang SC"'` |
| 思源黑体 | `'"Noto Sans SC"'` |
| 思源宋体 | `'"Noto Serif SC"'` |
| 宋体 | `'"SimSun"'` |
| 楷体 | `'"KaiTi"'` |

> 例：想让标题用宋体风格 → 把 serif 那行改成
> `serif: ['"Noto Serif SC"', '"SimSun"', 'serif'],`

## 3. 正文字号 / 行距 / 段落间距（文章阅读体验）

打开 `src/components/Markdown.tsx`，文件顶部注释就是调参指南。关键数字：

| 想调什么 | 位置 | 当前值 | 怎么改 |
| --- | --- | --- | --- |
| 正文字号 | 最外层 div 的 `text-[15px]` | 15px | 数字越大字越大（14~17 之间试） |
| 行距 | 同一个 div 的 `leading-[1.75]` | 1.75 | 觉得挤调大到 1.85，觉得松调小到 1.7 |
| 段落间距 | `case 'p'` 里的 `my-3` | 0.75rem | my-2 更紧凑，my-4 更疏 |
| 标题与上文距离 | `h2` 的 `mt-8`、`h3` 的 `mt-6` | 2rem / 1.5rem | 数字越大离上文越远 |
| 列表项间距 | `ul` 的 `space-y-1` | 0.25rem | space-y-2 更宽松 |

> Tailwind 数字换算：`my-1` = 0.25rem（≈4px），`my-2` = 0.5rem，以此类推。

## 4. 换主题色（现在的鼠尾草绿）

分两步，两个文件配合改：

### 第一步：`src/index.css` 的 `--primary`

找到 `:root` 里的 `--primary: 140 30% 36%;`（约第 32 行）。
颜色是 **HSL 格式**：`色相 饱和度% 亮度%`

| 色相值 | 颜色 | | 色相值 | 颜色 |
| --- | --- | --- | --- | --- |
| 0 | 红 | | 200 | 蓝 |
| 30 | 橙 | | 260 | 紫 |
| 60 | 黄 | | 330 | 粉 |
| 140 | 绿（当前） | | | |

> 例：想换蓝色主题 → `--primary: 210 40% 40%;`
> 深色模式对应的在 `.dark` 里也有个 `--primary`，建议一起调亮一点。

### 第二步：`tailwind.config.js` 的 `leaf` 色板

找到 `colors.leaf`（约第 33 行），这是一组从浅到深的绿（50 最浅，950 最深）。
换色系需要整体替换这组颜色。不会配色？两个偷懒办法：

1. 打开 <https://uicolors.app> 输入一个主色，它会自动生成整套色板，复制 50~950 的色值替换
2. 只微调：文章里大量用到 `leaf-100`（浅背景）、`leaf-600/700`（按钮和链接），
   优先保证这三档和谐即可

## 5. 背景色 / 深色模式

都在 `src/index.css`：

- **浅色背景**：`:root` 的 `--background: 60 11% 98%;`（现在是暖米白）
  想要纯白 → `0 0% 100%`；想要更暖 → 把 11% 调大到 20%
- **深色背景**：`.dark` 的 `--background: 150 14% 9%;`（深墨绿）
- 文字颜色对应的是 `--foreground`，一般不用动

网页右上角的 ☀️/🌙 按钮切换深浅色，两组颜色都要协调。

## 6. 首页排版（调区块顺序 / 删区块）

打开 `src/pages/Home.tsx`。首页从上到下是 4 个 `<section>`：

```
① Hero 个人介绍（约第 22 行）
② 精选文章（约第 64 行）—— md 头部 featured: true 的文章
③ 最新文章（约第 97 行）—— 自动显示最近 4 篇非精选
④ 话题标签云（约第 116 行）
```

- **调顺序**：整段 `<section ...> ... </section>` 剪切粘贴换位置
- **删区块**：整段删除（比如不想要"话题"区）
- **最新文章显示几篇**：第 17 行 `.slice(0, 4)` 的 4 改成别的数
- **精选卡片封面高度**：`h-36`（约第 77 行），`h-48` 更高
- **"开始阅读"按钮颜色**：第 37 行 `bg-leaf-600`

## 8. 每篇文章的图标和封面色（不改代码）

在每篇 md 的头部信息区改，不用碰代码：

```
emoji: 🔧                    ← Win + . 打开表情面板随便挑
colorFrom: "#e8f3ea"         ← 封面渐变起始色（浅色系好看）
colorTo: "#f6f9f1"           ← 封面渐变结束色
featured: true               ← 是否进首页精选区
```

配色偷懒法：照抄现有文章里你喜欢的几组，或者只改 emoji 不动颜色。

---

## 9. 动画（锦上添花，可不管）

- 页面区块入场是"从下方浮起淡入"：`tailwind.config.js` 的 `fade-up`，
  首页各 section 上的 `stagger-2/3/4` 控制依次延迟出现
- 首页 👋 挥手动画：`Home.tsx` 第 60 行的 `@keyframes wave`
- 不喜欢动画：把 section 上的 `animate-fade-up stagger-x` 删掉即可

## 10. 修改后的标准流程

```bash
npm run dev        # 本地预览，边改边看（保存即刷新）
# 满意后：
git pull           # 保险起见先拉一下
# VSCode 源代码管理面板 → 写说明 → ✓ 提交 → 🔄 同步更改
```

2~3 分钟后 https://eebolg.online 更新。

> 💡 **最重要的建议**：一次只改一处，预览确认好看再改下一处。
> 这样改坏了也知道是哪一步的问题，`git checkout -- 文件名` 精准还原。
