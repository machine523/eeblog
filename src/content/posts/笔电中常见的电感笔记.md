## 第一章 预备知识：电感的脾气

电感就是一圈线圈。它的本事也只有一个：**电流不能突变**。

### 脾气详解

**1. 阻碍电流的变化（惯性）**
电流想突然变大，它顶着不让；电流想突然消失，它使劲维持。
类比：水流里的"惯性水轮"——水闸突然关上，水轮还要转一会儿，会把管道里的水继续往前推。

**2. 用磁场储能**
电流流过时，能量存在磁场里；电流要减小时，磁场把能量放出来继续维持电流。

**3. 通直流、阻交流**
- 对直流：≈ 一根导线（只剩一点点绕线电阻 DCR）
- 对高频变化：≈ 一堵墙（频率越高越过不去）

### 和电容对照着记（对偶关系）

| | 电容 | 电感 |
|---|---|---|
| 稳住的对象 | **电压**不能突变 | **电流**不能突变 |
| 储能形式 | 电场 | 磁场 |
| 对直流 | 开路（隔断） | 导线（通过） |
| 对高频 | 短路（导通） | 开路（挡住） |

> **一句话：电容是"电压的稳定器"，电感是"电流的稳定器"。**

## 第二章 功率电感（开关电源的心脏，最重要的应用）

### 是什么
开关电源（Buck）里那颗大个子电感，在芯片的高速开关配合下，一边储能一边释放，把高电压平稳地变成低电压。

### 为什么需要
Buck 芯片内部的开关管每秒开合几十万次，输出的是一连串方波脉冲。电感在这里干两件事：

1. **削峰填谷**：开关导通时储能、关断时释能，把断断续续的电流"熨"成连续的电流
2. **和输出电容组成 LC 滤波**：电感挡变化、电容平电压，方波进去，平滑直流出来

**续流**：开关关断瞬间，电感的电流不能停——它会"逼着"电流从别的路径（下管）继续流动。这就是 MOS 课里"死区时间走体二极管"的原因。

### 怎么认出来
- **大个子**：几毫米见方（如 6.9×6.5mm），主板上最显眼的元件之一
- 位置：紧贴电源芯片，一端接开关节点（LX/SW），一端接输出电容墙
- 丝印带感值：1µH、2.2µH 之类

### 选型四参数（以实战件 PL1101 为例：1µH / 11A / 22A / 0.01Ω）

| 参数 | 含义 | 选错后果 |
|---|---|---|
| **感值**（1µH） | 储能力 | 太小→电流纹波大；太大→体积大、响应慢 |
| **额定电流**（11A） | 长期工作不烫的上限 | 长期过热、寿命折损 |
| **饱和电流**（22A） | 磁芯"装满"的临界点 | ⚠️ 峰值电流超过它，磁芯饱和、感值瞬间崩塌，电感变导线 → 烧开关管 |
| **DCR**（0.01Ω） | 绕组直流电阻 | 直接变发热损耗：P = I²R，效率杀手 |

> **选型三句话：感值看纹波，饱和看峰值（留足余量！），DCR 看效率。**

### 注意事项
- 功率电感是发热大户，也是 Buck 效率的主要瓶颈之一
- 大电流场合听得到"啸叫"（电感振动发声），往往和电感或其工作点有关

## 第三章 磁珠（高频噪声的"软电阻"）

### 是什么
长得像一颗黑色小方块（和电阻、电容差不多大），本质是把电感做成"**专门吸收高频**"的形式。

### 和普通电感的区别（关键认知）

| | 电感 | 磁珠 |
|---|---|---|
| 对付噪声的方式 | **挡回去**（储能型，把高频反射回去） | **吃掉**（耗能型，把高频变成热） |
| 类比 | 反弹墙 | 吸音棉 |

### 为什么需要
某路电源要给怕噪声的模块供电（音频、摄像头、时钟），或者某个模块自己会制造噪声——中间串一颗磁珠，**高频噪声过不去，直流供电不受影响**。

### 怎么认出来
- 位号常见 **BL / FB** 开头
- 串联在电源线或信号线上（不是到地！）
- 丝印标的是**阻抗**而不是感值：如 `120Ω@100MHz`（在 100MHz 频率下呈现 120Ω 阻力）
- 网络名线索：被磁珠滤过的电源常带 **_FIL** 后缀

### 典型参数
- 阻抗 @100MHz：几十 Ω ~ 几百 Ω
- 额定电流：看它串联在哪路电上，必须够
- DCR：越小越好（毫欧级），减少供电损失

### 注意事项
- **磁珠不是 0Ω 电阻**：它对高频有明显阻力，别随便跨接/替换
- 磁珠 + 对地电容 = 一个低通滤波器（磁珠挡、电容泄），图纸上它俩经常成对出现

## 第四章 共模电感（接口的 EMI 门卫）

### 是什么
一个磁芯上绕两组线圈，用在成对的差分信号线上（USB、HDMI 等）。

### 为什么需要（它很聪明）
差分信号是两根线上"一正一反"地传输：

- **正常信号**（一正一反）：两组线圈产生的磁场**互相抵消** → 信号畅行无阻
- **共模噪声**（两根线同方向的干扰）：磁场**叠加增强** → 被死死挡住

> 一句话：**认得出"自己人"和"敌人"——有用的信号放行，共模干扰拦截。**

### 怎么认出来
- 四个脚的小元件，横在接口的差分线上
- 位置：紧贴连接器（USB 口、HDMI 口附近）

### 注意事项
- 有方向/配对关系，换件注意别接错两组线圈
- 对正常信号的阻抗要尽量小，否则高速信号质量受损

## 第五章 升压电路中的电感（了解即可）

利用"电流不能突变"的另一面：**强行切断电感电流，它会憋出一个高电压**——这就是升压（Boost）电路的原理。

笔电里的身影：屏幕背光驱动（把低电压升到几十伏点亮 LED 灯条）等。

**辨认**：电感一端接电源，一端接开关管，开关管到地——和 Buck 的拓扑长得不一样。

## 第六章 快速判别流程（看到任何一颗电感类元件）

```
① 看个头和位置
   ├─ 大个子（mm 级）+ 紧贴电源芯片 LX 脚 → 功率电感（Buck 储能/滤波）
   ├─ 小黑头、串联在电源/信号线上        → 磁珠（吸高频噪声）
   ├─ 四脚、骑在接口差分线上            → 共模电感（EMI 门卫）
   └─ 一端接电源一端接开关管            → 升压电感

② 看丝印
   ├─ 标 µH（1µH、2.2µH）      → 功率电感
   └─ 标 Ω@100MHz（120Ω@100MHz）→ 磁珠

③ 看网络名
   └─ 带 _FIL 后缀的电源 → 刚经过磁珠滤波
```

## 第七章 丝印与选型常识速查

### 功率电感丝印（例：`6.9mm×6.5mm_1µH_M(±20%)_11A_22A_0.01Ω`）

| 字段 | 含义 |
|---|---|
| 6.9×6.5mm | 尺寸（越大电流能力越强） |
| 1µH | 感值 |
| M(±20%) | 精度（功率电感 20% 足够） |
| 11A / 22A | 额定电流 / 饱和电流 |
| 0.01Ω | DCR（直流电阻） |

### 选型三句话
- **感值看纹波**： datasheet 有推荐值和公式，别拍脑袋
- **饱和电流是红线**：峰值电流必须离它有距离
- **DCR 是效率**：大电流场合，DCR 每小一点，发热就少一点

### 磁珠选型三句话
- 阻抗看要滤的频率（100MHz 处的阻抗值是标称惯例）
- 电流必须够（它串在供电路径上）
- DCR 越小越好

## 第八章 新手常见误区

1. **"电感就是个大电阻"**——错。它对直流几乎是导线（只有毫欧级 DCR），它管的是"变化"
2. **"磁珠是 0Ω 跳线"**——错。它对高频是几十上百 Ω，换错/短接会放噪声过去
3. **"饱和电流无所谓"**——错。这是红线，碰了就不是性能问题是烧管事故
4. **"感值越大越好"**——过大则体积大、响应慢、成本高，按 datasheet 推荐来
5. **"电感不分方向所以随便焊"**——功率电感确实无极性，但共模电感的两组线圈有对应关系，不能接反
6. **"电感旁边的电容是滤波，那电感也是滤波"**——对一半：电感挡变化、电容平电压，LC 合作才是完整滤波器

## 三件套总结（电阻 / 电容 / 电感对照）

| | 电阻 R | 电容 C | 电感 L |
|---|---|---|---|
| 脾气 | 阻碍电流 | 电压不能突变 | 电流不能突变 |
| 能量 | 消耗（变热） | 储存（电场） | 储存（磁场） |
| 对直流 | 阻力 R | 开路 | 导线（+DCR） |
| 对高频 | 阻力 R | 短路 | 开路 |
| 在电源里的角色 | 分压/检测/限流 | 稳电压（储能+滤波） | 稳电流（储能+滤波） |
| 黄金搭档 | 和电容组成 RC（延时/滤波） | 和电阻组成 RC | 和电容组成 LC（电源滤波） |

> **三者关系一句话：电阻消耗能量，电容和电感储存能量；RC 管时间，LC 管电源。**
