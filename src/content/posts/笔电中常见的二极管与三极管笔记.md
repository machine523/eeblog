## 上篇：二极管

## 第一章 预备知识：二极管的脾气

### 单向门
电流只能从阳极（A）流向阴极（K），反向不通。

```
  阳极(A)          阴极(K)
─────▶|─────   电流只能朝箭头方向流
```

**符号与实物对应**：实物上有一道**色环/横线标记，那一端是阴极（K）**——和符号里的竖线对应。焊接和测量时最容易搞反的地方，先记住。

### 导通要"门票"：正向压降
二极管不是正向一接就通，要先跨过门槛电压（压降 Vf）：

| 类型 | 门票（压降） | 特点 |
|---|---|---|
| 普通硅二极管 | 约 0.6~0.7V | 最常见 |
| 肖特基二极管 | 约 0.2~0.4V | 压降低、速度快，笔电里的主力 |

**为什么笔电偏爱肖特基**：压降低 = 发热少 + 电平损失小。3A 电流下，硅管发热 2.1W，肖特基只要 0.9W。

### 万用表怎么量
二极管档：红表笔接阳极、黑表笔接阴极 → 显示压降（硅 0.5~0.7，肖特基 0.15~0.4）；反过来量应显示 OL（不通）。
**两个方向都通 = 击穿短路；两个方向都不通 = 烧断开路。必须两个方向都量过才能下结论。**

## 第二章 防反接 / 电源隔离

### 是什么
串联在电源入口，电流只许进、不许回。

```
输入电源 ──▶|── 系统供电
```

### 为什么需要
- 防止接反烧板（电源极性接反时二极管挡死）
- 多路电源汇合时，防止一路的电倒灌进另一路

### 怎么认出来
- 串联在电源路径上，个头不小（要过电流）
- 阴极朝向系统内部

### 注意事项
- 二极管会吃掉一个压降：19V 进来剩 18.7V——用肖特基就是为少亏一点
- 要过电流，选型看**额定电流**和**耐压**，还要算发热 P = Vf × I

## 第三章 二极管门电路（重点章节）

> 不用逻辑芯片，单靠二极管+电阻就能搭出"或门"和"与门"。笔电的电源使能汇聚电路里大量使用——**这是二极管在笔电里最体现智慧的用法**。

### 3.1 或门（OR）：谁都能叫醒

**结构**：多个输入各接一颗二极管，**阳极朝输入、阴极汇聚到一个节点**，节点挂一颗**下拉电阻**到地。

```
输入A ──▶|──┐
输入B ──▶|──┼── 输出 ──→ 后级
输入C ──▶|──┤    │
                 [下拉电阻]
                 │
                GND
```

**逻辑**：任何一个输入为高 → 电流穿过二极管把输出拉高；全部输入为低 → 下拉电阻把输出钉在低。

| 输入 | 输出 |
|---|---|
| 任意一路 = 高 | 高（≈ 输入 − 0.3V，肖特基压降） |
| 全部 = 低 | 低 |

**笔电实战**：某路 CPU 供电的使能信号，由"开机信号、Type-C 唤醒信号、PCH 的两路 GPIO"四路汇聚——**任何一个理由成立，这路电就该开**。四颗二极管（或两颗共阴极双二极管 BAT54C，一颗里面装两个）+ 一颗下拉电阻就实现了。

### 3.2 与门（AND）：谁都别拖后腿

**结构**：方向反过来——**阴极朝输入、阳极汇聚到节点**，节点挂**上拉电阻**到电源。

```
              电源
               │
            [上拉电阻]
               │
输出 ──────────┤
               │
输入A ──|◀─────┤
输入B ──|◀─────┘
```

**逻辑**：任何一个输入为低 → 通过二极管把输出**拽下来**；所有输入都高 → 上拉电阻把输出吊到高。

| 输入 | 输出 |
|---|---|
| 任意一路 = 低 | 低 |
| 全部 = 高 | 高 |

### 3.3 判别口诀（三秒读出逻辑）

| 二极管朝向 | 节点电阻 | 逻辑 | 读法 |
|---|---|---|---|
| 指向汇聚节点 | **下拉** | **或门** | 任一高能"灌"进来 |
| 背向汇聚节点 | **上拉** | **与门** | 任一低能"抽"走 |

### 3.4 为什么用二极管搭逻辑，而不用门电路芯片

1. **门芯片自己要吃电**——时序早期"电还没起来，逻辑先要工作"，鸡生蛋问题；二极管无源，不挑食
2. **天然隔离**——各信号源之间互不倒灌，谁拉高算谁的
3. **便宜、小**——两颗 SOT-23 解决四输入或门

**代价（也要知道）**：输出被吃掉一个压降（所以选肖特基）；没有整形能力，输出驱动能力弱，只适合接后级的逻辑输入脚。

## 第四章 钳位（把电压摁在安全范围）

### 是什么
利用二极管"过门槛就导通"的特性，把某个节点的电压**钳在一个上限或下限**。

### 为什么需要
芯片引脚有耐受范围（比如 0~3.3V）。异常电压来袭时（静电、感应尖峰），二极管导通把多余的部分泄掉：

- 信号想超过电源电压 → 被钳在"电源 + 0.7V"
- 信号想低于地 → 被钳在"−0.7V"（零下 0.7V，注意符号）

> 几乎每个芯片的 IO 内部都内置了这样的钳位二极管——这就是"信号电压不能超过芯片电源电压"这条规矩的物理来源（否则电流经钳位管倒灌进电源轨）。

### 注意事项
- 钳位只能应对**短暂的、小能量**的异常；持续过压靠它顶不住
- 正负两个方向分别需要不同朝向的二极管

---

## 第五章 稳压二极管（齐纳管）：反向工作的怪胎

### 是什么
普通二极管反向加压是截止的，但加到某个临界值会**击穿**。稳压二极管故意利用这个特性：**反向击穿后，两端电压死死咬在一个固定值**（比如 5.6V），输入再高它都只吃自己的那份。

```
输入 ──[电阻]──┬── 稳定的 5.6V 输出
               │
              ▽ 稳压管（反向接法！）
               │
              GND
```

### 怎么认出来
- 符号比普通二极管多一个小拐角（像 Z）
- **反向接入电路**（阴极朝高电压）——这是它最反常的地方

### 笔电里的用途
- 简单的基准电压、过压保护
- 给某个节点设定电压上限

### 注意事项
- 必须串联限流电阻——击穿后电流没有限制会烧管
- 精度有限，精密基准另有专门的基准芯片

---

## 第六章 TVS / ESD 保护管（接口的保安）

### 是什么
专门对付**静电和瞬间高压**的二极管。平时完全隐身（相当于不存在），电压一旦超过阈值瞬间导通，把冲击能量泄放到地。

### 为什么需要
USB、HDMI 这些**对外接口**，每次插拔都可能带进几千伏的人体静电——不打掉，接口芯片当场阵亡。

### 怎么认出来
- 并在接口信号线/电源线和地之间，紧贴连接器
- 封装小，位号常带 ESD/TVS 字样
- 高速接口用的是低电容 TVS（电容太大会拖垮高速信号——电容笔记的道理在这里复用）

### 与稳压管的区别
长得像、原理近，但 TVS 专为**瞬间大能量**设计（响应快、吃能量猛），稳压管是为**持续稳压**设计。保护场合别用稳压管顶替。

---

## 第七章 续流二极管（给电感留退路）

### 是什么
并在电感类负载（或开关电源回路）两端的二极管。

### 为什么需要
回忆电感的脾气：**电流不能突变**。开关关断瞬间，电感电流无处可走，会憋出高压打坏元件。续流二极管给它一条"退路"，让电流继续转圈流完。

### 怎么认出来
- 并在电感性负载两端，**反向接法**（正常供电时它不导通，关断反峰时才导通）

---

## 第八章 二极管家族速查表

| 成员 | 标志特征 | 本职 | 笔电里的岗位 |
|---|---|---|---|
| 普通硅二极管 | 压降 0.7V | 单向导通 | 少用 |
| **肖特基** | 压降 0.3V、速度快 | 低损单向导通 | 防反接、或门、续流——**绝对主力** |
| 稳压管（齐纳） | 反向工作、符号带拐角 | 咬住固定电压 | 基准、过压保护 |
| **TVS/ESD 管** | 并在接口对地 | 吃静电浪涌 | 所有对外接口 |
| 双二极管（如 BAT54C） | 一颗装两个、共阴极 | 省空间 | 二极管或门常客 |
| LED | 通电发光 | 指示 | 电源灯、充电灯 |

### 选型常识
- **压降**：低压场合/大电流场合选肖特基
- **电流**：过流的场合额定电流留一倍余量
- **耐压**：反向要承受的电压，留一倍余量
- **速度**：高频开关场合看反向恢复时间，肖特基最快

# 下篇：三极管（BJT）

## 第九章 预备知识：三极管的脾气

### 一句话本质
**小电流控制大电流**——基极（B）流进一点小电流，集电极（C）到发射极（E）就放行一股大电流。

```
        C（集电极）
        │
   B ──┤         NPN：B 给个高电平（对 E 高出 0.7V）→ C-E 导通
（基极）│
        E（发射极）
```

### 笔电里 99% 的用法：开关
三极管有"放大"和"开关"两种工作状态。模拟电路里玩放大；**笔电数字电源世界里几乎只当开关用**——要么全开，要么全关。

### 开门条件
- **NPN**：B 比 E **高**约 0.7V → 开（高电平开门）
- **PNP**：B 比 E **低**约 0.7V → 开（低电平开门）
- 口诀：**N 高开，P 低开**

### 三个关键参数
| 参数 | 含义 | 直觉 |
|---|---|---|
| β（放大倍数） | C 电流是 B 电流的多少倍 | 当开关用时往大了给驱动，别抠 |
| Vbe ≈ 0.7V | 开门门票 | 基极必须串电阻限流 |
| Icm | C 能过的最大电流 | 按负载选 |

## 第十章 开关与电平转换（最常用）

### 是什么
用一个低压小信号（如 GPIO 的 3.3V），控制另一路较高电压的通断。

### 典型模板一：NPN 低边开关

```
负载电源 ──[负载]──┬── C
                   │
控制信号 ──[电阻]──┤ B
                   │
                   E ── GND
```
控制信号为高 → 三极管开 → 负载接地导通。

### 典型模板二：NPN 驱动 PNP（高边开关）

GPIO 电压不够控制高电压回路时，用 NPN 当"中间人"：

```
高电压 ── PNP(E)……(C) ── 负载
              │
             (B)
              │
GPIO ──[R]── NPN ── GND     NPN 把 PNP 的基极拉到地，PNP 开门
```

GPIO 高 → NPN 开 → PNP 基极被拉低 → PNP 开 → 高压侧导通。
**这是分立负载开关的经典结构**（笔电里更多用集成芯片，但原理相同）。

### 反相器（顺带的身份）
NPN 开关天然反相：输入高 → 输出低。图纸上一路信号极性不对时，常用它翻个面。

### 怎么认出来
- 三脚小元件（SOT-23），位号常是 Q 或 PQ
- 基极必串一颗电阻（限流，几 KΩ）
- 常配上拉/下拉电阻定默认态

### 注意事项
- **基极必须串限流电阻**——B-E 之间等效一个二极管，不限流会烧
- 当开关用，驱动电流要给足（进入深度饱和），否则半开发热

## 第十一章 驱动放大（GPIO 力气不够时）

### 是什么
芯片 GPIO 只能输出几毫安，带不动蜂鸣器、灯条、风扇这类负载——三极管当中间放大级：GPIO 推三极管，三极管推负载。

### 典型场景
- 蜂鸣器驱动
- LED 灯条电流放大
- 风扇电源开关

### 判别特征
三极管后面跟着的是"吃电流的货"，而控制源头是个弱小的信号脚。

## 第十二章 三极管 vs MOS 管（已学内容的对照）

| | 三极管（BJT） | MOS 管 |
|---|---|---|
| 控制方式 | **电流**控制电流 | **电压**控制电流 |
| 开门条件 | B-E 流过电流（约 0.7V 门槛） | G-S 电压差（阈值数伏） |
| 静态消耗 | 基极持续耗电流 | 栅极几乎不耗电 |
| 导通损耗 | 固定饱和压降（0.1~0.3V） | 电阻性（毫欧级，大电流完胜） |
| 笔电分工 | **小信号**：电平转换、反相、小驱动 | **大电流**：电源开关、功率转换 |

> 一句话：**小信号逻辑用三极管，电源功率用 MOS 管。**

## 第十三章 快速判别流程

### 看到二极管
```
① 看位置和朝向
   ├─ 串在电源路径          → 防反接/隔离
   ├─ 多颗汇聚一点 + 电阻    → 门电路（朝向+电阻方向定 OR/AND）
   ├─ 并在信号对电源/地      → 钳位
   ├─ 反向接 + 符号带拐角    → 稳压管
   ├─ 接口处并对地           → TVS/ESD
   └─ 并在电感/负载两端      → 续流
② 看类型：压降小 = 肖特基；反向接 = 稳压/TVS
```

### 看到三极管
```
① NPN 还是 PNP（箭头：NPN 朝外，PNP 朝里）
② 发射极接地 = 低边开关；发射极接电源 = 高边开关
③ 基极有没有串电阻（没有 = 图纸可疑）
④ 后面跟谁：负载 → 开关/驱动；另一颗管 → 电平转换/组合开关
```

## 第十四章 新手常见误区

1. **"二极管正向就通"**——要跨过压降门票（0.7V/0.3V），门票钱从信号里扣
2. **"二极管符号方向随便看"**——色环端是阴极，和符号竖线对应；焊反 = 门装反了
3. **"稳压管和普通管一样接"**——稳压管是**反向**接入工作的
4. **"三极管基极可以直连信号"**——必须串限流电阻
5. **"二极管门电路输出是满幅的"**——被吃掉一个压降，后级阈值要留裕量
6. **"三极管和 MOS 管随便互换"**——小信号行，大电流场合三极管的发热会让你后悔
7. **"只量一个方向就判二极管好坏"**——必须双向都量：一通一断才是好的
