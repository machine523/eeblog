# 📝 如何添加 / 修改文章（小白指南）

> 这个文件只是说明书，不会出现在网站上（文件名以 `_` 开头的都会被自动忽略）。

## 添加一篇新文章，只要 3 步

1. **复制**任意一个现有 `.md` 文件，改个文件名（建议用英文小写 + 短横线，如 `my-first-post.md`）。
   文件名就是文章的网址，比如 `my-first-post.md` → 网址 `/posts/my-first-post`
2. **修改文件开头的信息区**（两个 `---` 之间的部分，见下文说明）
3. **在第二个 `---` 下面写正文**，支持 Markdown 格式，保存后刷新网页就能看到

## 文章头部信息（frontmatter）逐项说明

```
---
title: 文章的标题                    ← 显示在列表和文章页顶部
date: 2026-09-12                     ← 发布日期，格式必须是 年-月-日
tags: 随笔, 生活                      ← 标签，多个用逗号隔开（用于筛选和归档）
excerpt: 一句话摘要。                 ← 显示在文章卡片上，建议 50 字以内
emoji: 📖                            ← ★ 文章图标！换成任何你喜欢的 emoji
colorFrom: "#e8f3ea"                 ← 封面渐变起始色（浅色系最好看）
colorTo: "#f6f9f1"                   ← 封面渐变结束色
featured: true                       ← true = 显示在首页「精选文章」；false 或不写 = 不显示
---
```

## 如何给文章换图标（emoji）？

- 改 `emoji:` 后面那个表情符号就行。Windows 下按 `Win + .`（句号键）可以打开表情面板挑选
- 推荐搭配：技术文 → 💻 ⚛️ 🔧 ⌨️｜生活文 → 🍂 ☕ 🌿 🏡｜读书笔记 → 📖 📚｜随笔 → ✍️ 💭 🌱
- `colorFrom` / `colorTo` 是图标背后那块渐变底色的两个端点颜色，建议选浅色系；
  不会配色可以偷懒：只改 emoji，颜色沿用模板里现有的几组，都很清新
- 如果不写 `emoji` 和颜色，会自动用默认的 🌿 和浅绿渐变

## 正文支持的格式

| 写法 | 效果 |
| --- | --- |
| `## 小标题` | 章节标题（带绿色竖条） |
| `**加粗**` | **加粗** |
| `*斜体*` | *斜体* |
| `` `代码` `` | 行内代码（绿底小字） |
| `> 引用的话` | 绿色引用块 |
| `- 列表项` | 圆点列表 |
| ` ```语言名 ` 开头和结尾包住代码 | 深色代码卡片（支持 tsx / css / js 等语言标记） |
| `[链接文字](https://...)` | 链接 |

## 常见问题

- **改了文件网页没变化？** 确认文件保存了，然后刷新浏览器；本地开发时一般会自动热更新
- **文章没出现在列表里？** 检查两个 `---` 是否都在行首、`date` 格式是否为 `2026-09-12` 这种
- **想删除文章？** 直接把对应的 `.md` 文件删掉（或移出这个文件夹）即可
