## 第一章 预备知识：电阻的脾气

电阻的本事只有一个：**阻碍电流**。用电阻，就是利用"阻碍"带来的三个结果：

### 结果一：电阻上的电压和电流成正比（V = I × R）
1A 电流流过 1Ω 电阻，电阻两端就产生 1V 压降。
→ 派生出：**检流**（测压降反推电流，第五章）、**限流**（第四章）

### 结果二：两个电阻串联，电压按阻值比例分配
→ 派生出：**分压**（第三章）

### 结果三：电阻把电能变成热量消耗掉（P = I² × R）
→ 派生出：**吸收/消耗能量**（第八章），以及选型时的**功率**问题（第十一章）

### 阻值的直觉尺度

| 量级 | 直觉 |
|---|---|
| 零点零几 Ω（mΩ 级） | 几乎是一根导线 |
| 几 Ω ~ 几百 Ω | 小阻力 |
| 几 KΩ ~ 几百 KΩ | 大阻力（信号世界的主力） |
| 几 MΩ | 接近断开，只留一条"缝隙" |

## 第二章 上拉 / 下拉（数量最多）

### 是什么
一端接信号线，另一端接电源（上拉）或接地（下拉）的电阻。作用是：**没人驱动这条线时，给它一个确定的默认电平**。

### 为什么需要
芯片的引脚如果悬空（谁也不驱动它），电平是"飘"的，可能随机是高是低——电路就乱了。上拉/下拉电阻像一个默认值：**没人说话时，线就停在我规定的电平上**。

### 怎么认出来
- 一端信号线、一端电源轨或地
- 阻值特征：**几十 KΩ ~ 几百 KΩ**（最常见 10K、47K、100K）
- 精度 ±5% 即可，功率都是最小的（1/20W 级）

### 典型参数
- 10K / 47K / 100K 是三大常见值
- 选大省电但抗干扰差，选小则相反——设计上的权衡

### 注意事项
- **同一信号线的上拉/下拉，必须上拉到"接收方"的电源轨**——上拉到别的电源上，可能出现信号比接收芯片电源还高的情况，造成倒灌损伤
- 上拉电阻并联一颗电容，就变成了 RC 滤波/延时电路（见电容笔记第三章）
- 判断"该是什么电平"时，先找这颗电阻：它决定了信号的"出厂默认态"

## 第三章 分压（把电压按比例变小）

### 是什么
两个电阻串联接在"电源"和"地"之间，从中间引出一个按比例缩小的电压。

```
 Vin ──[R1]──┬── Vout（= Vin × R2/(R1+R2)）
             │
            [R2]
             │
            GND
```

### 为什么需要
芯片的检测脚/反馈脚只认一个固定的小电压（比如 0.6V），但要监测的电压可能是 3.3V、19V——用分压电阻把大电压"按比例缩小"再送进去。电源芯片的输出电压就是靠这两个电阻的比例设定的。

### 怎么认出来
- **两颗电阻串联**，一端电源、一端地，中间引出线
- 中间那根线通常通向芯片的 FB（反馈）/ SENSE（检测）脚

### 典型参数
- 阻值多在 KΩ ~ 几百 KΩ 级
- **精度要求高：±1%（丝印带 F）**——比例不准，输出电压就不准

### 注意事项
- 这是少数"精度要紧"的电阻应用场景之一
- 改这两个电阻的比例 = 改电源输出电压（调试技巧，也是风险来源）

## 第四章 限流（保护）

### 是什么
**串联**在电流路径里，把电流限制在安全范围内的电阻。

### 为什么需要
有些元件"不知节制"：LED 直接接电源会瞬间烧掉；MOS 管的栅极充电太猛会产生振铃。串一颗电阻，电流就有了上限。

### 怎么认出来
- 串联在回路中（不是到地）
- 阻值较小：几 Ω ~ 几百 Ω

### 典型场景
- LED 指示灯串的电阻（限流，决定亮度）
- MOS 管栅极串联的几 Ω 小电阻（限制栅极充放电速度，抑制振铃）
- 信号线上串的 22Ω~33Ω（同时兼做第八章的阻尼作用）

### 注意事项
- 串联电阻会消耗功率，过电流场合要核算 P = I²×R 别超功率
- 它同时会"吃掉"一点电压——阻值不能随意加大

## 第五章 检流（把电流变成电压来测量）

### 是什么
串联在电源路径上的**极小阻值精密电阻**，利用 V = I × R，把看不见的电流变成可测量的压降。

### 为什么需要
系统想知道某路电现在吃了多少电流（比如监测功耗、过流保护）。电流没法直接量，就让它流过一颗已知阻值的小电阻，量两端压降反算：**I = V ÷ R**。

### 怎么认出来（特征非常明显）
- 阻值极小：**0.01Ω（10mΩ）级**，丝印像 `0.01ohm`
- 精度高：**±1%**（它的阻值直接决定测量的准头）
- 功率大：**1W 级、大封装（1206 等）**——它要实打实地过大电流
- 经常两三颗并联（进一步降低阻值、分摊发热）

### 注意事项
- 千万别把它当 0Ω 跳线拆掉或短接——那是系统的"电流表"
- 布局上压降的两端要用专门的采样线引出（开尔文接法），否则会测不准

## 第六章 基准 / 校准（芯片的"尺子"）

### 是什么
接在芯片特定功能脚上的精密电阻，给芯片内部电路当**参考标准**。

### 为什么需要
有些芯片需要一个外部"标尺"来校准自己——比如用一颗精确电阻做基准，校准自己输出驱动的强度。

### 怎么认出来
- 阻值不大但**精度 ±1%**（几十~几百 Ω，如 150Ω）
- 所接引脚名字通常带 RCOMP / RREF / IREF 之类
- 阻值由芯片数据手册规定

### 注意事项
- **不能当普通电阻随便换值**——它不是上拉下拉，是芯片的尺子，换错值芯片工作就失准
- 精度必须保证

## 第七章 偏置 / 反馈（给振荡电路定工作点）

### 是什么
并在晶振两端的大电阻（典型 **10MΩ**）。

### 为什么需要
晶振振荡电路内部是一个放大器，需要一颗大电阻把它的直流工作点"拴"在合适的位置，振荡才能启动。

### 怎么认出来
- **MΩ 级阻值**是它的标志（10MΩ 最常见）
- 位置：晶振两脚之间

### 注意事项
- 阻值偏差要求不高，但不能省——少了它晶振可能不起振，整机没时钟

---

## 第八章 消耗能量（阻尼 / 吸收）

### 是什么
利用"电阻把电能变热"的脾气，**故意消耗掉不想要的能量**。

### 两个典型场景
1. **RC 吸收电路（Snubber）**：电阻和电容串联接在开关节点到地之间，开关瞬间产生的高频振铃能量，被电阻消耗成热——毛刺被"吃掉"（详见电容笔记第七章）
2. **信号线串联阻尼**：高速信号线上串 22Ω~33Ω 小电阻，吸收信号反射，让波形干净

### 怎么认出来
- Snubber：电阻 + 电容**串联**到地，常标 "ns"（预留不装）
- 阻尼：串在信号线中间的小阻值电阻

---

## 第九章 0Ω 电阻（特殊的"假电阻"）

### 是什么
阻值为零的电阻——**它不是电阻，是工具**。

### 四个用途
1. **配置跳线**：同一张图纸适配不同机型，装哪颗不装哪颗决定走哪条路（装了的接通，标 "ns" 的断开）
2. **BOM 选配**：两个信号源二选一接同一个网络，各串一颗 0Ω，量产时只装其一
3. **测量/隔离点**：调试时挑开它就能断开一段电路，不用割线
4. **单点连接**：两处地/两个网络需要"只在一处相连"时用它

### 注意事项
- 图纸上大量 0Ω 标注 "ns" 是正常的——预留文化，别当成缺件
- 它确实有微小的电阻（几十 mΩ），大电流路径上不能随便用它替代铜线

## 第十章 快速判别流程（看到任何一颗电阻，问四句话）

```
① 串联还是并联（到地/电源）？
   ├─ 一端信号、一端电源/地，几十~几百K → 上拉/下拉（默认态）
   ├─ 两颗串联、中间出线              → 分压（检测/反馈）
   ├─ 串联在电流路径、阻值极小 ±1%    → 检流
   ├─ 串联在电流路径、阻值几~几百Ω    → 限流/阻尼
   ├─ 接芯片功能脚、±1%               → 基准/校准
   ├─ 并在晶振两端、MΩ 级             → 偏置
   └─ 阻值为 0                        → 跳线/配置/测量点

② 阻值量级？（mΩ 检流 / Ω 限流 / KΩ 上下拉 / MΩ 偏置）

③ 精度？（±1% = 分压/检流/基准，事关准确；±5% = 上下拉，无所谓）

④ 功率/封装？（大封装大功率 = 走真电流；0201 小功率 = 纯信号）
```

## 第十一章 丝印读法与选型常识

### 丝印解读（以 `100K_0201_1/20W_F` 为例）

| 字段 | 含义 |
|---|---|
| 100K | 阻值 100KΩ（4R7 = 4.7Ω；0R = 0Ω） |
| 0201 | 封装尺寸（越小功率越小） |
| 1/20W | 能承受的最大功率 |
| F | 精度 ±1%（J = ±5%，K = ±10%） |

### 封装与功率对照（常见值）

| 封装 | 典型功率 | 用途感觉 |
|---|---|---|
| 0201 | 1/20W | 纯信号 |
| 0402 | 1/16W | 纯信号 |
| 0603 | 1/10W | 信号/小电流 |
| 0805 | 1/8W | 中小电流 |
| 1206 | 1/4W 以上 | 检流/功率场合 |

**功率校核**：P = I² × R，算出来必须小于标称功率并留余量——信号电阻不用算，电流路径上的必须算。

### 选型三句话
- 上下拉：随便选（KΩ 级、±5%、最小封装）
- 分压/检流/基准：**精度就是功能**，±1% 起步
- 走电流的：先算功率，再看封装

## 第十二章 新手常见误区

1. **"电阻都是耗电流的"**——错。上下拉、分压走的是微安级电流，它们的本职是"定电平"，不是耗电
2. **"0Ω 电阻没用"**——错。它是配置跳线和测量点，是工程师故意留的活口
3. **"精度无所谓"**——分压、检流、基准三类电阻，精度直接就是功能
4. **"小电阻可以随便短接/拆掉"**——检流电阻拆掉，系统的电流监测就瞎了
5. **"标了就是有"**——标 "ns" 的是预留位，实际没贴
6. **"阻值对了就行"**——还要看功率。阻值对、功率不够，通电就烧
