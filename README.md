# 🌿 拾光小栈 · 个人博客

一个清新简洁风格的个人博客，用来记录硬件开发工程师的日常学习笔记。
基于 **React + TypeScript + Vite + Tailwind CSS** 构建，文章用 **Markdown 文件夹**管理，写完即发布。

---

## ✨ 功能特性

- 📝 **Markdown 写文章**：往 `src/content/posts/` 丢一个 `.md` 文件就是一篇新文章，无需改代码
- 🏷️ **标签分类**：按文章头部的 `tags` 自动汇聚话题（技术 / 生活 / 阅读……），支持筛选
- ⭐ **精选文章**：`featured: true` 的文章显示在首页精选区
- 🗂️ **自动归档**：按年份自动分组的时间线
- 🌙 **深色模式**：跟随系统，可手动切换并记忆
- 📱 **全端适配**：电脑、手机、平板都有良好排版
- 📖 **技术文档排版**：紧凑行距、代码块卡片、引用块，适合学习笔记

## 🚀 快速开始（本机）

| 方式 | 操作 |
| --- | --- |
| 一键启动（推荐） | 双击 `启动博客（无黑窗）.vbs`，浏览器自动打开，无黑窗口 |
| 关闭后台服务 | 双击 `关闭博客.bat` |
| 命令行启动 | `npm run dev` → 打开 http://localhost:3000 |
| 打包生产版本 | `npm run build`（产物在 `dist/`） |

> 首次在新电脑上使用，先运行一次 `npm install` 安装依赖（需要 Node.js 20+）。

## 📁 目录结构（常用文件都标了注释）

```
blog/
├── src/
│   ├── content/posts/          ← ★ 文章全在这里，一篇一个 .md 文件
│   │   ├── _如何添加文章.md     ← 写文章必读说明书（不会被发布）
│   │   └── *.md                 ← 你的文章
│   ├── data/posts.ts           ← 站点信息（昵称/简介/社交链接）+ 文章自动加载逻辑
│   ├── pages/                  ← 各页面排版（首页/文章/详情/归档/关于）
│   ├── components/             ← 通用组件（导航/页脚/文章卡片/Markdown 渲染器）
│   │   └── Markdown.tsx        ← ★ 正文排版样式（行距、字号、间距都在这调）
│   └── index.css               ← ★ 全站配色（想换主题色改这里）
├── tailwind.config.js          ← 字体、绿色色板、动画（带注释）
├── docs/                       ← 部署与多电脑管理指南
├── deploy/nginx.conf           ← 云服务器 Nginx 配置模板
├── .github/workflows/          ← 推送后自动部署到服务器
├── 启动博客（无黑窗）.vbs       ← 本机一键启动（后台运行）
├── 启动博客.bat                ← 本机启动（带黑窗口，调试用）
└── 关闭博客.bat                ← 关闭本机后台服务
```

## ✍️ 日常写文章（3 步）

1. 在 `src/content/posts/` 复制任意一篇 `.md`，改成新文件名（英文小写 + 短横线）
2. 修改文件开头的信息区（标题、日期、标签、`emoji:` 图标、是否精选）
3. 写正文，保存 → 本地预览立即更新；推送到 GitHub 后线上自动更新

详细说明看 [`src/content/posts/_如何添加文章.md`](src/content/posts/_如何添加文章.md)。

## 🎨 常见自定义

| 想改什么 | 改哪里 |
| --- | --- |
| 博客名 / 昵称 / 简介 / 邮箱 | `src/data/posts.ts` 里的 `site` 对象 |
| 文章字体 | `tailwind.config.js` 的 `fontFamily` |
| 主题色 / 背景色 | `src/index.css` 的 `:root` 变量（带注释） |
| 正文行距 / 段落间距 | `src/components/Markdown.tsx`（文件顶部有调参指南） |
| 首页模块顺序 | `src/pages/Home.tsx`（移动对应 `<section>` 即可） |

## 🌐 部署到云服务器

这是一个**纯静态网站**：`npm run build` 后把 `dist/` 文件夹丢到任何静态服务器（Nginx）即可访问。

推荐两种部署方式，详细步骤见 **[docs/部署到云服务器.md](docs/部署到云服务器.md)**：

1. **手动部署**：本机构建 → 上传 `dist/` → Nginx 托管（适合第一次上线）
2. **自动部署（推荐）**：配置好 GitHub Actions 后，**在任何电脑上把文章 push 到 GitHub，网站自动更新**——甚至直接在 GitHub 网页上编辑 md 文件都行

多电脑同步写作的工作流见 **[docs/多台电脑同步管理.md](docs/多台电脑同步管理.md)**。
